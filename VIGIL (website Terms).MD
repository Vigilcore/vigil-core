# VIGIL | OPERATIONAL TERMS & CANONICAL DEFINITIONS

## 1. PROJECT IDENTITY
VIGIL is a Layer 0.5 Security Standard designed to restore human awareness in Web3 environments. This document serves as the definitive reference for the system’s core primitives and operational boundaries.

## 2. CANONICAL DEFINITIONS

### Intent Synchronization
**Decoupling perception from malicious UI shifts**
The process of validating that a user's visual target (the address they believe they are interacting with) matches the technical payload (the address actually being processed) before cryptographic execution.

### Sub-Frame Autopsy
**Heuristic analysis at the retinal threshold**
A forensic processing standard that completes security audits (entropy check, similarity indexing, and provenance mapping) within 12ms—ensuring the verdict is rendered faster than a single frame refresh of a standard display.

### Sovereign Context
**Local mapping with absolute zero data leakage**
A zero-knowledge data architecture where the user's trust graph and interaction history are stored exclusively in the browser's Local IndexedDB, preventing external telemetry or server-side monitoring.
